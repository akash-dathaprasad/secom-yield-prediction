# Data

The raw SECOM data is not stored in this repository. The notebook downloads it automatically.
To download it by hand, get `secom.zip` from https://archive.ics.uci.edu/dataset/179/secom and unzip it.
You need two files: `secom.data` (590 sensor readings per lot) and `secom_labels.data` (pass/fail label and timestamp).

Source: McCann, M. and Johnston, A. (2008). SECOM. UCI Machine Learning Repository.
